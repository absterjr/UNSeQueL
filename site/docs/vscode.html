VS Code

The UNSeQueL extension highlights .unsequel files and runs queries from the editor, piping selections through the unsequel CLI so a file's own # source directives supply the data connection.

Commands

Command (Ctrl+Shift+P)What it does
UNSeQueL: Run SelectionRuns the selected lines with unsequel run <file> --lines A:B.
UNSeQueL: Run FileRuns the whole file with unsequel run <file>.
UNSeQueL: Open REPLOpens an interactive unsequel repl terminal.

Both run commands are also in the editor context menu. The file is saved first so line numbers match the selection.

Install

The extension is not on the Marketplace yet. Install from the repository:

cd compiler/editors/vscode
npx @vscode/vsce package
code --install-extension unsequel-vscode-0.2.0.vsix

Or open compiler/editors/vscode in VS Code and press F5 for an extension development window — the fastest way to try it.

To remove it later: code --uninstall-extension unsequel.unsequel-vscode.

Settings

  • unsequel.executable — the command to run (default unsequel). Set an absolute path if the CLI is not on PATH.

Without the extension

Any editor that can send text to a terminal can run a REPL session: start unsequel repl in a terminal and use Terminal: Run Selected Text in Active Terminal. The selected stages paste into the REPL and execute on a blank line.
