# UNSeQueL sample data

These small CSVs mirror the repository's shared tutorial dataset at
[`examples/spec/`](https://github.com/absterjr/UNSeQueL/tree/main/examples/spec).
They are included
inside the npm package so the five self-contained `examples/real/` programs
run after installation as well as in a repository checkout. Keep the copies in
sync; `tests/dogfood.test.ts` checks that they match.
